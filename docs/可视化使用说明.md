四个入口统一位于 `scripts/visualize/`，仅读取已有结果。单方法重建查看器通过 `--algorithm legacy_g99|tum_native` 选择方法；新方法既支持 `--results <试验目录>`，也支持位置参数。运动与肌电同步查看器默认加载v002，可用 `--algorithm legacy_g99` 或界面“运动重建”切换老方法。

- [肌电查看器](#肌电查看器)
- [运动与肌电同步查看器](#运动与肌电同步查看器)

## 运动重建查看器

在项目根目录运行，默认读取受试者001的 `trial_011.mat` 及对应重建结果。

```powershell
python scripts/visualize/visualize_reconstruction.py
```

依赖现有的 NumPy、SciPy、Matplotlib 和 Python tkinter。当前环境已完成窗口与交互检查。程序也可从其他工作目录通过脚本绝对路径启动。

### 同步显示

- 左侧三维图显示原始38个Vicon标记点、FK预测标记点、模型关节中心与骨段连线。尺骨、桡骨和手段分别显示，肩胛用参考骨性特征连线表示。
- 手部显示半透明手掌、掌骨连线及五指分节示意。尺寸随受试者手段比例缩放，五指保持固定张手姿态，整体由手段位姿驱动。数据中的12自由度不包含手指关节角。
- 肘部尺骨系、前臂中段桡骨系、腕骨系和手系同步显示，X/Y/Z分别为红/绿/蓝。桡骨系的显示原点放在桡骨连线中点，方向采用模型桡骨坐标系。腕骨系用虚线，手系用实线。局部骨段坐标轴和关节瞬时旋转轴分别显示。
- q9肘屈伸、q10旋前旋后、q11腕屈伸、q12腕桡尺偏的正向旋转轴同时显示，并标注当前角度。角度方向沿用已保存的模型定义。
- 窗口顶部显示动作编号、中文名称和数据集英文描述，切换试验时自动更新。
- 世界坐标总览显示12个角度面板，并比较IK与滤波曲线。局部观察自动显示参考骨段下游的角度，曲线采用当前选择的IK或EKF方法。单位为度，红色游标和数值对应同一采样时刻。
- 底部时间轴可访问全部1828帧，采样率500 Hz，时长3.654秒。播放按实际时间推进，界面按绘图刷新速度显示相应帧。逐帧按钮可查看每个原始采样点。
- 选择“骨架采用”的IK或滤波结果，三维骨架、FK预测点、误差和当前数值一起切换。

### 操作

顶部“全部自由度 / 局部坐标系观察”切换显示方式，默认使用“全部自由度”：在世界坐标中播放完整上肢运动，并显示q1–q12全部12条角度曲线。选择“局部坐标系观察”后可固定某一骨段；局部参考初始选项为桡骨，显示q11和q12两条腕关节曲线。参考坐标系下拉框提供以下选项。

| 固定参考坐标系 | 显示的角度 |
|---|---|
| 肱骨 | q9–q12 |
| 尺骨 | q10–q12 |
| 桡骨 | q11、q12 |
| 腕骨 | q12 |
| 胸廓 | q1–q12 |
| 锁骨 | q3–q12 |
| 肩胛骨 | q6–q12 |
| 手（反向观察） | q9–q12，辅助检查上游相对手的运动 |

局部观察将每帧的三维几何乘以所选骨段位姿的逆，因此该骨段的模型坐标原点和方向在画面中固定，骨段下游继续按重建结果运动。固定坐标轴X/Y/Z分别为红/绿/蓝，图中轴标签注明骨段名称。原点使用模型骨段坐标原点，例如桡骨系原点位于近端，腕骨系原点位于腕部。曲线和关节角数值沿用保存的角度定义。

局部视图显示固定参考骨段及其下游骨架和相关关节旋转轴，手系用于反向观察时显示肱骨至手部。原始标记点及误差连线在局部视图中隐藏，侧栏点位和拟合RMS仍对应原始世界坐标中的重建结果。显示范围根据整段轨迹一次计算，在播放时保持稳定。点击曲线可定位时间并突出相应旋转轴，固定参考坐标系保持所选骨段。切换试验或IK/EKF方法时自动重建局部显示。播放、慢放、时间轴和逐帧操作共用原有控件。

| 操作 | 控件 |
|---|---|
| 播放/暂停 | 底部按钮或空格 |
| 慢放 | 速度0.1、0.25、0.5倍 |
| 逐帧 | 上一帧/下一帧，或左右箭头 |
| 定位时间 | 拖动底部滑块，或点击关节角曲线 |
| 定位指定帧 | “定位帧”输入框，界面帧号从1开始 |
| 选择关节 | 点击对应曲线，三维图突出关联骨段并显示该关节的当前旋转轴 |
| 旋转/缩放 | 三维图拖动、滚轮、底部Matplotlib工具栏 |
| 近看某个姿态 | 左侧“当前姿态”暂停并按当前点位调整范围，“全程范围”恢复覆盖整个动作的范围 |
| 观察腕部 | “腕部近景（跟随运动）”以腕部为中心播放，滚轮可调整近景范围，选择其他视角或范围可退出跟随 |
| 查看局部坐标与自由度 | “肘 / 前臂 / 腕局部坐标系”和“q9–q12旋转轴与角度”可分别开关 |
| 检查标记点 | 左侧下拉框查看测量/预测坐标及位置差，红圈突出对应点 |
| 比较拟合 | 勾选“显示位置误差连线” |
| 显示名称或筛选点 | 左侧点列表、主点按钮及点名下拉框 |
| 查看其他试验 | “打开结果目录”选择相应 `trials/trial_XXX` 文件夹 |

左侧控制面板可滚动。世界坐标总览显示原始世界坐标，局部视图显示所选骨段坐标，长度统一为mm，三个轴等比例。手掌和五指为固定张手示意。

### 质量与颜色

橙色标题及 `*` 表示该角存在先验依赖。当前数值出现其他质量标记时显示红色，具体原因可在左侧所选关节说明中查看。位置残差使用当前显示方法与对应原始标记计算。

骨架来自保存的G99模型与已估计角度。测量点来自原始MAT，模型骨段坐标和绝对角仍具有标定先验依赖。视觉检查可检查几何连接、动作方向、连续性和点位拟合，角度准确性还需结合独立测量评估。

### 指定结果与导出预览

```powershell
python scripts/visualize/visualize_reconstruction.py --results outputs/TUM/reconstruction/legacy_g99/subj_001/trials/trial_011 --method ekf
python scripts/visualize/visualize_reconstruction.py --preview outputs/TUM/reconstruction/legacy_g99/subj_001/trials/trial_011/interactive_preview.png --frame 850
python scripts/visualize/visualize_reconstruction.py --self-check
```

命令行 `--frame` 从0开始。程序按时间匹配原始标记与角度，并核对模型哈希。需要静态检查图时，使用上述 `--preview` 命令导出。

## 肌电查看器

入口为 `scripts/visualize/visualize_emg.py`，实现位于 `src/emg_visualization/`。依赖沿用 NumPy、SciPy、Matplotlib 和 Python tkinter。

在项目根目录运行：

```powershell
python scripts/visualize/visualize_emg.py
```

默认加载迁移后的文件，不使用时间戳目录：

```text
outputs/TUM/emg_preprocessed/v001_hu2018/subj_001/trial_005/emg_preprocessed.npz
```

默认路径按项目位置解析，从其他目录通过脚本绝对路径启动也有效；相对命令行参数按当前工作目录解析。

### 图形与交互

- **通道波形**：各通道纵向排列，共享时间轴，显示中文肌肉名及缩写。可切换带通sEMG、包络、归一化包络；默认叠加包络、各通道独立纵轴，可选择统一纵轴。归一化包络未勾选时，各通道从0到本通道峰值上方5%；勾选时统一从0到至少1.05，峰值超过1时自动统一扩大范围，避免截断。
- **激活热图**：固定显示归一化包络，统一0–1色标，灰色为缺失值。长记录最多1800个时间分箱，以分箱均值显示。
- **功率谱**：显示已带通信号的Welch功率谱，每通道使用最长的连续、有限、非边界片段，最多2048点窗。虚线标记20/600 Hz，点线标记50/100 Hz参考，不代表自动检测到干扰。频谱不等同于滤波前的原始频谱。
- **时间与质量**：可切换记录起点相对时间或原始EMG时钟。浅橙底纹标记边界敏感区，缺失值不填补，质量标记保留显示。顶部与窗口标题显示中文任务名称并保留原始英文描述，导出预览也附中文任务名称；同时显示采样率、时长和实际归一化范围，诊断结果按文件元数据标记。
- **缩放与平移**：使用底部Matplotlib工具栏。波形页十行联动，缩小时按显示分箱保留峰值和谷值，放大后显示完整采样点；热图与频谱页有各自独立的视图范围。

### 切换数据

“打开数据”可选择符合格式的任意预处理NPZ。方法版本、受试者、试验下拉框支持目录导航；上一条/下一条按当前方法版本中的受试者和试验目录排序，可跨受试者切换。

“选择数据根目录”可切换结果集合，例如 `outputs/TUM/_checks/emg_preprocessed/`；其下应为 `<方法版本>/subj_*/trial_*/emg_preprocessed.npz`。导航排除 `_backups/` 和隐藏工作目录。

切换后保留信号类型、纵轴设置、包络开关、时间显示方式和当前页签，时间范围重置为新记录全长。加载时核验字段、形状、单位、通道名称和时钟；有manifest时要求状态为complete。加载失败会显示原因并保留当前数据。

```powershell
python scripts/visualize/visualize_emg.py --data outputs/TUM/emg_preprocessed/v001_hu2018/subj_001/trial_006/emg_preprocessed.npz
python scripts/visualize/visualize_emg.py --data outputs/TUM/emg_preprocessed/v002_hu2018_with_rest/subj_001/trial_001/emg_preprocessed.npz
```

### 导出与验证

“导出当前图”保存PNG，默认目录为 `outputs/TUM/analysis/figures/emg/`。也可不开窗口生成预览：

```powershell
python scripts/visualize/visualize_emg.py --preview outputs/TUM/analysis/figures/emg/waveform.png
python scripts/visualize/visualize_emg.py --view heatmap --preview outputs/TUM/analysis/figures/emg/heatmap.png
python scripts/visualize/visualize_emg.py --view spectrum --preview outputs/TUM/analysis/figures/emg/spectrum.png
python scripts/visualize/visualize_emg.py --signal normalized --preview outputs/TUM/analysis/figures/emg/normalized.png
python scripts/visualize/visualize_emg.py --self-check
```

`--view` 和 `--signal` 也可指定桌面窗口的初始页签与信号类型。自检通过隐藏Tk窗口检查三个信号模式和页签、共享时间轴、真实试验切换、错误文件保留当前数据、波形峰谷保留，以及源文件检查前后SHA-256一致性。全部操作仅读取预处理结果，不执行数据重算、不改写肌电或角度标签。

## 运动与肌电同步查看器

默认方法为新方法v002，直接运行原命令即可。界面“运动重建”切换 `tum_native`（v002）或 `legacy_g99`；顶部“方法版本”仍指肌电预处理版本，两者分别选择。切换或加载失败会保留当前数据并说明原因。`--reconstruction` 指定当前重建方法的结果根目录，下接 `subj_*/trials/`。

```powershell
python scripts/visualize/visualize_emg_kinematics.py
python scripts/visualize/visualize_emg_kinematics.py --algorithm legacy_g99
python scripts/visualize/visualize_emg_kinematics.py --algorithm tum_native --preview outputs/TUM/_checks/emg_kinematics_v002.png
python scripts/visualize/visualize_emg_kinematics.py --algorithm tum_native --self-check
```

新方法读取 `v002_anchored7/.../emg_aligned_native.npz` 的七列标签，右侧显示末四列肘腕角，前臂明确标为扭转代理。左侧用保存的骨段位姿和骨架显示包含肩部及肩带位移的运动，不能套用旧12角FK。核对模型与原始输入哈希、任务、单位、逐点肌电时钟、质量及脉冲映射；已保存标签必须与按原报告映射重采样的结果一致。

旋转SLERP、平移线性插值，不外推、不跨长缺口。新方法位64是滤波边界，老方法位64是先验依赖，界面分别解释；新方法采用其自身相对有效掩码。下文具体q9–q12、EKF和12角描述仅适用于老方法，公共播放、联动、肌电和导出操作适用于两者。

入口位于 `scripts/visualize/visualize_emg_kinematics.py`，实现位于 `src/emg_kinematics/`。复用预处理肌电读取、波形／热图绘制、个体模型及正向运动学，不重算角度或同步偏移。动画从同一试验的 `ekf_angles.npz` 读取完整12角和 `T_world_thorax`，按照既有EMG偏移重采样；角度及平移使用线性插值，旋转使用SLERP，不外推、不跨越缺失或过长间隙。完整角度的末四列须与已有同步四角标签一致。

在项目根目录运行：

```powershell
python scripts/visualize/visualize_emg_kinematics.py
```

默认肌电为 `outputs/TUM/emg_preprocessed/v001_hu2018/subj_001/trial_005/emg_preprocessed.npz`，默认角度来自v002同一试验的同步标签；选择老方法时读取 `outputs/TUM/reconstruction/legacy_g99/subj_001/trials/trial_005/emg_aligned_distal.npz`。默认路径不含时间戳运行目录，可从其他工作目录通过入口脚本绝对路径启动。

### 布局和操作

手部示意包含四指和向掌侧外展的拇指，拇指用暖棕色突出，并随手掌刚性运动；没有额外估计拇指或手指自由度。

- **左侧**：使用全部12个重建自由度和胸廓位姿显示躯干示意、肩带、上臂、前臂及手部运动，不固定肩部或上臂。世界坐标仅减去首个有效胸廓平移作为固定显示原点。下方仍只列出关注的四角数值与质量说明。紫色横杆帮助观察前臂旋转，彩色短线表示肘腕四个关节轴。三维窗口可拖动旋转，使用按钮重置视角。手指为固定示意形状，未重建手指关节。
- **右上**：q9肘屈伸、q10前臂旋前／旋后、q11腕屈伸、q12腕桡偏／尺偏四条角度曲线，显示单位为度。`*`表示该角存在先验依赖，浅橙色区表示其他质量问题；当前时刻有游标和采样点。
- **右下**：十通道肌电随窗口高度自适应，一屏显示全部通道，无须纵向滚动；右侧角度区与肌电区约按30%／70%分配。默认归一化包络、独立纵轴，支持带通sEMG、未归一化包络、统一纵轴和包络叠加。也可切换激活热图，肌电边界敏感区保留底纹。
- **顶部**：播放／暂停、倍速、进度条、逐采样移动、肌电文件选择、方法／受试者／试验选择及上一条／下一条。中英文任务名称、版本和归一化范围随数据更新。

角度和肌电曲线的横向缩放／平移联动，红色游标共用同一肌电记录相对时间。在没有启用工具栏缩放／平移工具时，单击任意角度或肌电曲线可跳转时间，三维姿态同步更新。播放使用实际经过时间定位，不逐一播放2000 Hz的每个采样点；“±1采样”按肌电时间轴移动0.5 ms。

默认时间范围是四角均有有限估计值的共同区间，**不代表逐角严格质量全部通过**。勾选“完整记录”可查看完整肌电；缺少完整12角或胸廓位姿时隐藏运动姿态并显示原因，不保持上一帧；已有有限四角仍可独立显示。动画保留完整12角的质量提示，其他质量问题和q10先验依赖仍允许显示但会明确标注。角度正负方向沿用模型定义，不依据屏幕方向判断。

切换试验保留信号类型、纵轴、热图和完整记录选项，重置当前时刻和视角。导航跳过没有现成同步角度文件的试验；手动选择不匹配文件会提示原因并保留原数据。只有具有对应运动学标签的放松试验才能联合显示。

### 数据核验与边界

加载时核对受试者／试验／任务编号、原始EMG路径、预处理肌电与同步标签的逐点时间戳、角度单位、质量掩码及个体模型SHA-256。全程仅读取源数据。

曲线使用已有的2000 Hz同步角度估计，其来源是500 Hz运动学标签的重采样，不能解释为2000 Hz独立角度测量。三维示意使用该受试者模型的完整12角和胸廓位姿，显示肩部及远端运动；手掌和手指为固定示意形状，不重建手指关节。

同步依据是脉冲窗口持续时间匹配，硬件延迟和漂移尚未独立确认。q10绝对相位仍有先验依赖。此程序用于检查时间关系与质量，不将角度估计变成独立真值，也不额外补偿肌电与运动之间的生理延迟。

python scripts/visualize/visualize_emg_kinematics.py --algorithm legacy_g99 --self-check
