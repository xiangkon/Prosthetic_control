# 新方法运动重建

仅维护 `v002_anchored7` 姿态约束方法，统一入口为 `scripts/reconstruct_tum_native.py`。旧方法 `legacy_g99` 独立保留。新方法不读取旧角度进行标定、初始化或求解。

## 运行与结果管理

```powershell
# 先选少量记录，保持500 Hz原始时刻
python scripts/reconstruct_tum_native.py --subjects 1 --trials 43 45 --workers 2 --emg
# 仅标定
python scripts/reconstruct_tum_native.py --subjects 1 --calibrate-only
# 明确选择全量532条任务表引用记录
python scripts/reconstruct_tum_native.py --all --workers 2 --emg
```

配置为 `configs/motion_reconstruction/tum_native/v002.json`。默认输出到 `outputs/TUM/reconstruction/tum_native/v002_anchored7/`；`--output-root` 指定的基目录下仍追加版本名。默认单进程，`--workers` 控制1–8个试验级进程。

匹配模型、配置、代码指纹、源文件和同步请求的结果直接复用。遇到不兼容模型或试验会拒绝覆盖，必须选择独立 `--output-root`；此入口不支持 `--replace`。本次入口收敛保留经过核对的既有v002缓存指纹，不修改原生报告或模型；后续数值实现变化仍会使缓存失效。

## 模型与坐标

七列依次为 `TH_RV_X/Y/Z`、`EL_FE_FUNC`、`FA_TWIST_PROXY`、`WR_FE_FUNC`、`WR_RD_FUNC`。肩部为相对个人Task 0参考的胸廓—上臂旋转向量，包含肩带贡献，不是旧GH三欧拉角；前臂为技术段扭转代理，未经独立验证为真实桡尺旋转。另保存三维肩带有效位移，不称为已验证的解剖自由度。

每人按任务表选择Task 0稳定参考，冻结局部模板与校准参数。标记点簇以稳健Kabsch获得骨段姿态；短缺口插补、连续段滤波、边界及原始掩码分别记录，长缺口不贯通。内部单位m、rad、s，正式输出保留500 Hz原始时刻。

采用观测骨段姿态作初值，对完整观测帧进行6次有界标记拟合，各角组修正范数上限15°，肩带位移修正上限35 mm。目标同时考虑标记残差、修正量和肘腕局部相对姿态误差；后者按3°归一化。仅在连续段内平滑小幅修正，逐帧检查最终代价，衰减或回退导致局部代价升高的修正。

功能轴采用单独指定的校准动作，按试验划分拟合和验收组；只有验收组姿态误差中位数、P95和12°超限比例满足检查才接受调整。模型保留试验角色，校准记录不作为独立留出评价。

## 输出与质量

每人保存 `model.json`；每试验保存 `trials/trial_NNN/reconstruction.npz`、`report.json`，同步成功时另有 `emg_aligned_native.npz`。NPZ无需pickle，保存七角、肩带位移、观测与模型骨段位姿、骨架、标记、源索引、逐角质量及相对有效掩码。

共有质量位覆盖缺失、点簇退化、模型失配、参考／轴先验、插值、滤波边界、近π分支及测量信息不足。4096表示点簇拟合异常，8192表示观测不支持的旋转步长。肘／前臂姿态失配门槛12°，腕部20°，测量条件标准差门槛20°；腕门槛同时作用于腕屈伸、桡尺偏及导出标签掩码，不改变已求解轨迹。

`relative_valid` 用于此模型内的相对变化筛选，`absolute_valid` 始终为假。测量条件标准差不包含全部标定、软组织及模型误差。质量通过率表示规则下的标签覆盖，不是角度精度。

## sEMG同步与查看

`--emg` 读取原始肌电脉冲并核对MoCap持续时间，独立保存七列同步标签。无法核实则报告不可用，不套用旧方法偏移。按逐角质量筛选后重采样，不跨长缺口生成可信标签；原生角度和质量定义保持不变。

```powershell
# 默认打开v002运动与肌电同步查看器
python scripts/visualize/visualize_emg_kinematics.py
# 显式选择方法和肌电记录
python scripts/visualize/visualize_emg_kinematics.py --algorithm tum_native --data outputs/TUM/emg_preprocessed/v002_hu2018_with_rest/subj_001/trial_005/emg_preprocessed.npz
# 单独查看七坐标、标记和骨架
python scripts/visualize/visualize_reconstruction.py --algorithm tum_native --results outputs/TUM/reconstruction/tum_native/v002_anchored7/subj_001/trials/trial_043
```

同步查看器检查受试者、任务、单位、模型哈希、原始文件路径与哈希、时间轴、质量掩码及已保存标签的一致性。动画读取v002保存的骨段位姿与骨架，按已有脉冲映射到肌电时间；平移线性插值、旋转SLERP，不外推或跨长缺口。手指固定示意；2000 Hz显示标签来自500 Hz重采样，并非独立角度测量。硬件延迟、漂移和生理延迟尚未独立确认。

## 验证与比较

`subj_001/trial_043` 当前检查中最大相邻角变化约0.46°、最大骨架节点位移约2.4 mm，原始标记重投影误差P95约18.5 mm；单条试验实跑求解约2.7 s、端到端约7.6 s，耗时受机器负载影响。运动段质量覆盖为肩部100%、肘／前臂88.7%、腕部63.7%，腕姿态失配P95约23.6°。运动段定义为手臂拟合标记相对胸廓速度中位数>0.05 m/s，只用于统计分层。

全量532条配对趋势、按受试者／动作的选择证据及限制见[新老方法比较](新老方法比较.md)。坐标、质量与姿态约束的合成验证见 `tests/test_tum_native.py`，同步校验见 `tests/test_emg_kinematics.py`。低点位残差、轨迹平滑或跨方法高相关均不能证明解剖角更精确。
