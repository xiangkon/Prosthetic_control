## v002全量对比核心结果与数据选择

### 证据范围与统计口径

结果来自2026年11月20日保存的 `legacy_g99_vs_v002_trends_v001`，对比新方法 `v002_anchored7` 与老IK、EKF。覆盖6人532个配对试验（含16个Task 0），成功读取1064个旧方法—试验组合，失败0；产生14896行试验—角度—筛选策略指标。本次文档整理不重跑分析，也不改写源报告、CSV或原生标签。

主汇总使用共同质量有效段，排除Task 0；两曲线稳健活动范围P95−P5均须≥5°，可分析时长须≥1 s。连续有效段内使用0.1 s二阶Savitzky–Golay平滑与求导，去除半窗边缘，不跨缺口插值。方向以±5°/s划分，任一曲线运动即计入分母，一动一静算不一致，两者静止不计入。总体指标按试验等权取中位数，受试者并非等权。

排名采用另一层汇总：只保留IK/EKF均符合条件的试验—角度，先平均IK/EKF，再在受试者×任务×角度内对重复取中位数。受试者得分先任务等权、再角度等权；动作得分先受试者等权、再角度等权。Pearson不取绝对值、直接作描述性算术平均，未做Fisher变换；缺失及低活动单元不填零。排名得分不能与下表总体中位数直接混为一种统计量。

### 异常尾部与实际选数建议

在EKF主汇总纳入试验中，前臂Pearson<0有14条、<0.8有97条；桡尺偏分别16条、79条。0.8只是描述性切分，不是已验证验收阈值。优先复查前臂 `subj_005/trial_031`（r=−0.676）、桡尺偏 `subj_003/trial_031`（r=−0.840）、肩部Y `subj_003/trial_035`（r=−0.933）和腕屈伸 `subj_005/trial_019`（r=−0.532）。trial编号不是Task编号。

- 小规模流程验证可优先查看001、002及两角排名靠前动作，同时检查逐角有效覆盖、持续时长、幅度、速度和肌电质量；这只是候选核验顺序，尚未建立最终训练样本清单。
- 面向肘腕四自由度训练，七坐标排名和两角排名分别提供整体与薄弱坐标证据；两角得分不能代替四角联合质量检查。005前臂、003桡尺偏应重点复查，不直接按受试者整批删除。
- 正式评价先冻结受试者／任务／重复划分与质量规则，再在训练或开发集选择阈值和归一化参数。按全体一致性挑选的“容易子集”只能作为明确标注的子集实验，不能替代完整留出评价。Task 0作为参考／静息数据单独管理，不因未进入动态排名而删除。

两方法使用相同来源的标记观测，一致性不是外部真值验证。肩部是包含肩带贡献的胸廓—上臂旋转向量，并非旧GH三角；前臂是技术段扭转代理。未做时间平移、DTW或动态幅度拟合。全部1064条旧方法输入记录缺少历史原始数据哈希，当前来源核对通过仍不能证明历史输入未变。本报告只支持当前TUM记录内部的候选选择，不证明TUM优于MHH，也不建立解剖角度精度结论。

## v002趋势分析流程

入口：`python scripts/analysis/analyze_reconstruction_trends.py`。默认分析现有全部配对试验，分别比较老IK、EKF与`v002_anchored7`；不重建、不修改原生结果。默认输出到`outputs/TUM/reconstruction/comparisons/legacy_g99_vs_v002_trends_v001/`；已有目录拒绝覆盖，再运行须指定独立`--output`。

小范围运行示例：

```powershell
python scripts/analysis/analyze_reconstruction_trends.py --subjects 1 --trials 43 --output outputs/TUM/reconstruction/comparisons/trends_check
python -m unittest discover -s tests -p test_trend_analysis.py -v
```

### 比较坐标

复用`viewer_data.py`的002比较约定。肩部先通过共同胸廓/上臂技术点簇转换老模型的骨段旋转，再将两方法的胸廓—上臂姿态分别按同一Task 0稳定窗口的平均旋转归零，取旋转向量三分量。它不是老方法GH1/2/3逐列比较，不能声称新方法已经转换为旧GH角。

肘、前臂和腕四角由002冻结模型在参考姿态的局部敏感性确定符号，再按同一参考窗口的各自角度中位数对齐。IK/EKF分开计算参考参数，无动态回归、幅度缩放或逐试验翻转。方向依据是模型局部约定，不是全范围解剖等价的验证。完整参考旋转、技术系变换、方向和截距保存于`manifest.json`。

### 指标和筛选

- 相同MoCap时间戳配对，无插值或时间规整；核对来源路径、当前源哈希、模型哈希、角度列及rad单位。
- 主统计使用两方法共同质量有效帧。老方法除64（绝对坐标依赖先验）外，其他非零质量位均拒绝；肩部合并前八角质量位。新方法采用保存的`relative_valid`；肩部旋转向量范数超过170°也拒绝。
- 每个连续有效段单独做0.1 s二阶Savitzky–Golay平滑和求导，剔除半窗边缘，不跨缺口。可分析数据不足1 s时不计算主指标。
- Pearson、Spearman评价角度曲线；角速度Pearson评价变化过程。方向按±5°/s分为增加、减少、静止；任一曲线运动的帧进入方向一致率分母，一动一静视为不一致，两者静止均不纳入。
- 幅度用P95−P5；报告新/旧幅度比。两条曲线任一幅度小于5°时保留指标但标记低活动，不进入主趋势汇总；Task 0也不进入主汇总。
- `--smoothing-s`、`--speed-deg-s`、`--min-rom-deg`可修改相应参数。默认值用于探索分析，不是精度验收标准。

各试验等权，输出中位数和四分位数；不拼接所有帧。`finite_sensitivity`保留有限角度但忽略质量掩码，用于观察筛选的选择效应。它包含不可靠估计，不可替代主统计。全体汇总按试验加权，另提供逐受试者统计以检查试验数量不均。

### 输出与解释

基于保存的逐试验指标对受试者和动作排序：`python scripts/analysis/rank_reconstruction_consistency.py`。结果在分析目录下的`rankings/`，已有目录拒绝覆盖。主指标为七角等权Pearson：仅使用IK/EKF同时纳入的试验—角度，先平均两种旧方法，再对重复试验取中位数；受试者间按任务平衡，动作间按受试者平衡。方向一致率、Spearman和角速度相关提供独立排名；另输出所有比较组均可评价的共同单元敏感性排名。该排序描述当前可评价运动的一致性，不是精度或显著性排名。

仅比较前臂旋转和桡尺偏时，沿用同一筛选及汇总流程，对两角等权评分并保留单角得分：

```powershell
python scripts/analysis/rank_reconstruction_consistency.py --angles FA_TWIST_PROXY WR_RD_FUNC --output outputs/TUM/reconstruction/comparisons/legacy_g99_vs_v002_trends_v001/rankings_forearm_wrist_deviation
```

`REPORT.md`为主要结果；`trial_metrics.csv`包含质量覆盖率、纳入状态及所有逐试验指标；`summary_by_angle.csv`、`summary_by_subject.csv`、`summary_by_task.csv`分别按角度、受试者和任务汇总。`manifest.json`保存参数、运行时间、输入NPZ哈希及失败记录。

高相关只表明趋势相近，不能证明角度值、幅度或解剖意义正确。前臂仍是整体扭转代理，可能与肘角耦合；肩部统一坐标包含肩带贡献。质量筛选可能保留更容易的一段运动，应同时看覆盖率、低活动排除数量和敏感性统计。老报告缺少历史源哈希时，当前来源核对不能证明历史原始数据未改变。本分析不进行滞后校正，因此时序差异仍会降低指标。
