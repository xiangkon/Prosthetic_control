# 多自由度假肢的连续同步控制
## 1. 运动识别方法
### 1.1 模式识别：做什么动作
传统的模式识别一次只选择一个动作。如果是传统的单标签分类器，并且规定每次只执行一个动作，只要分类结果正确，其他自由度就不会被激活。但是识别错误是仍会出现非预期运动。

本质：通过限制允许执行的动作来避免多余的自由度输出，而非从本质上消除耦合

#### 优点
1. 能够学习非线性决策边界，区分线性回归难以分离的复杂肌电特征分布
2. 显式判断各自由度的运动状态，用于抑制非预期运动

#### 缺点
1. 若设计多个自由度与运动状态，若将所有运动组合定义为类别，随着自由度增加，运动组合数会指数性增长，会增加数据集与识别模型的复杂性。
2. 预测的灵活性不足，由于预测的输出是运动类别，所有难以直接根据使用者的运动意图调节关节连续角度与速度，难以完成精细操作。若要实现连续比例控制，需要增加额外机制，例如用肌电信号的幅值决定运动速度。
3. 操作负担增加，需要频繁切换运动模式，或通过反复启动、停止来调整关节位置，从而增加认知负担和操作时间。

### 1.2 连续运动回归：运动多少，运动多快
连续运动回归直接预测多个自由度运动分量，当输入特征包含耦合的信息，模型无法准确区分运动意图时，原本静止的自由度可能产生非零输入，控制量该为0的自由度控制量不为0。

#### 耦合的来源
1. 一个肌肉控制多个自由度，例如肱二头肌控制肘屈曲和前臂旋后两个运动
2. 一个自由度由多个肌肉共同控制，例如腕伸展有尺侧腕伸肌和桡侧腕伸肌共同控制
3. 每个通道收集的sEMG信号不纯净，即使两块肌肉在功能上独立，由于电极的检测范围，肌肉空间位置及信号传播，也可能收集到彼此混合的信号

| 对比 | 传统单标签模式识别 | 多输出连续回归 |
|------|------|------|
| 输出 | 离散动作类别   | 各自有度连续控制量 |
| 同时多自由度控制 | 需要扩展   | 天然支持 |
| 比例控制 | 需要额外机制   | 直接实现 |

## 2. 串扰解决思路
1. 从生理层面：为不同的自由度选定独立的控制肌群
2. 从特征层面：从sEMG数据集中提取各运动自由度对应的特征
3. 从控制方面：建立特征与各关节运动量的关系

### 目前解决耦合、串扰的方法，回答现有的进展
1. NMF约束方法：研究如何减少非目标自由度的激活

2. 分而治之模型：研究如何通过肌肉分组和协同改善解码

3. 概率加权回归：研究如何在同时控制能力与独立控制能力之间取得平衡

### 关注的四自由度及其控制肌肉（可直接测量）列表
| 运动 | 肌肉 |
|------|------|
| 肘屈曲 | 肱二头肌、肱桡肌 |
| 肘伸展 | 肱三头肌 |
| 腕旋前 | 旋前圆肌 |
| 腕旋后 | 肱二头肌 |
| 腕伸展 | 桡侧腕长伸肌、尺侧腕伸肌 |
| 腕屈曲 | 桡侧腕屈肌、尺侧腕屈肌 |
| 腕尺偏 | 尺侧腕屈肌、尺侧腕伸肌 |
| 腕桡偏 | 桡侧腕屈肌、桡侧腕伸肌 |


1. 其中肘屈伸和腕旋前旋后存在部分肌肉共享，即肘屈曲和腕旋后都共享肱二头肌
2. 前臂旋转运动识别较难，旋后肌与旋前方肌位置深，难采集，目前相关论文间接地从其他肌肉中辨识得到该运动（Li, 2023）
3. 腕屈伸和桡尺偏相关的肌肉采集简单，但采集的肌肉同时参与多个自由度，不能独立地分离。目前对腕屈伸运动地研究较多，很多研究忽略了腕桡尺偏。

## 3. 研究思路
1. 先不急于设计解耦算法，而是把这八个运动方向的肌肉参与关系建立起来，再通过实验验证这些关系能否体现为可区分的sEMG特征。根据肌肉生理功能划分自由度耦合关系，再针对不同类型的耦合设计有针对性的解码策略

### 将肘前臂与腕关节分别进行研究的两个假设
1. 肘屈伸与前臂旋转可以利用不同肌肉的激活组合实现一定的解耦
2. 腕屈伸与桡尺偏可以利用四组腕部肌肉的激活模式进行解耦
