# TUM 肘、前臂及腕肌电预处理

入口位于 `scripts/preprocess_emg.py`，实现位于 `src/emg_preprocessing/`，版本参数位于 `configs/emg_preprocessing/`，结果位于 `outputs/TUM/emg_preprocessed/<版本>/`。原始数据和已有角度、同步结果保持原样。主要处理入口放在 `scripts/` 根目录，可视化入口放在 `scripts/visualize/`。

## 使用

在项目根目录运行，依赖沿用 `requirements.txt`。

```powershell
python scripts/preprocess_emg.py --self-check
python scripts/preprocess_emg.py --subjects 1 --limit-trials 2 --output outputs/TUM/_checks/emg_preprocessed
python scripts/preprocess_emg.py
```

第二条仅是小范围验证：归一化峰值只来自所选两条运动试验，运行记录标为 `diagnostic=true`，不能当作全运动序列归一化结果。默认配置为 `v002_hu2018_with_rest`，第三条处理全部六人中 `trial_info.mat` 正式 EMG 列表引用的 Task 0–30；不要求有 MoCap 配对。可用 `--subjects 1 2` 限定受试者。眼动任务和未被有效列表引用的记录不参与。

## 初始放松姿态数据

`v002_hu2018_with_rest` 导出初始放松姿态 Task 0 与运动 Task 1–30，沿用相同十通道和滤波参数。受试者001的 Task 0 为 trial_001、trial_002、trial_003；其他人的有效编号按各自 `trial_info.mat` 获取，不统一假设是001–003。

```powershell
python scripts/preprocess_emg.py --config configs/emg_preprocessing/v002_hu2018_with_rest.json
python scripts/visualize/visualize_emg.py --data outputs/TUM/emg_preprocessed/v002_hu2018_with_rest/subj_001/trial_001/emg_preprocessed.npz
```

输出位于 `outputs/TUM/emg_preprocessed/v002_hu2018_with_rest/`。配置的 `task_ids` 指定导出任务，`normalization_task_ids` 单独指定参与峰值拟合的任务（1–30）；Task 0 不参与拟合，直接使用同一受试者运动峰值归一化，不执行静息基线扣除。报告分别记录放松试验编号和参与归一化的试验编号，NPZ保存 `normalization_task_ids` 和 `task_description_zh`。放松信号若超过运动峰值，归一化结果可以大于1，数据不截断。

原 `v001_hu2018` 仅含运动任务，其配置与结果保持原样。指定旧配置可复现旧范围：

```powershell
python scripts/preprocess_emg.py --config configs/emg_preprocessing/v001_hu2018.json
```

可通过 `--root` 指定 TUM 原始数据根目录，通过 `--output` 指定项目 `outputs/` 内的输出基目录。最终路径固定为 `<输出基目录>/<方法版本>/`，不增加时间戳目录；运行时间仅写入报告（UTC+08:00）。先在临时工作目录计算，全部完成后再发布到固定路径，旧结果移至 `<输出基目录>/_backups/<方法版本>/backup_001/` 等编号备份。若同一版本已有不同参数，需创建新版本配置。小范围验证使用独立的 `_checks/emg_preprocessed` 输出基目录，程序拒绝用诊断结果替换全量结果。

## v001_hu2018 基线

参考 Hu 等（2018）论文 III-B 节。研究对象限定为十个主要肘、前臂及腕肌肉通道；这属于本项目的通道选择，并非论文用于肩臂协同分析的十三通道集合。

| 双极通道（1起始） | 名称 |
|---|---|
| 11、12 | BICl、BICs |
| 13、14 | TRClg、TRClt |
| 15 | PRNT |
| 16、17 | FCR、FCU |
| 23 | ECU |
| 27、28 | BRD、ECR |

FCR 电极可能同时包含掌长肌。通道映射依据官方 `aux_functions/getMuscleNames.m`；双极转换为第 `2i-1` 列减第 `2i` 列，依据 `emg_uni2bi.m`。幅值单位沿用 `plot_EMG.m` 的 μV 标注，不另乘缩放因子。

流程：2000 Hz 原始双极信号 → 20–600 Hz Butterworth 零相位带通 → 取绝对值 → 2 Hz 二阶临界阻尼零相位低通 → 每人每通道除以其全部所选运动序列的包络最大值。归一化峰值包含端点；v002额外导出的放松姿态不参与峰值计算。保留全部原始采样时刻，无降采样、动作相位拉伸或新增时间对齐。

论文未公开滤波系数与边界处理，以下是本实现的明确约定，不能据此宣称逐样本复现原作者结果：

- `butter(N=4, btype='bandpass')` 的 N 为低通原型阶数，变换后单向带通总阶数为8；前后向滤波的幅频响应为单向响应的平方。论文的“四阶”是否指带通总阶数未进一步明确。
- 临界阻尼低通采用 `H(s)=wn²/(s+wn)²`，阻尼比1，双线性变换并预畸变。2 Hz 定义为单向响应的 −3 dB 点，因此前后向复合响应在2 Hz约为 −6 dB。它不是二阶 Butterworth 低通。
- 两级均使用 `sosfiltfilt`，奇对称延拓，延拓长度2 s；记录长度必须严格超过2 s。各试验独立滤波，不将不同动作拼接。
- 标记首尾各1 s为边界敏感区，`edge_valid=false`；保留其数值，不声称其余样本不存在端点影响。这是工程质量标记，不是论文规定。
- 整流后包络的负端点值截为0，并记录每通道截断样本数。原始波形含非有限值或整列恒定的通道不填补，输出NaN并附质量标记；没有有效归一化峰值时也输出NaN。

这个版本用于离线论文方法基线。全序列受试者峰值可能包含未来测试试验的信息。用于运动解码评估时，应在另一个版本中按训练集或独立校准数据拟合归一化参数；跨受试者评估也需明确测试受试者的校准方案。零相位处理会使用未来样本，不能直接充当在线控制算法。

## 输出与追溯

```text
outputs/TUM/emg_preprocessed/v001_hu2018/
    config.json
    manifest.json
    subj_001/
        normalization.json
        trial_004/
            emg_preprocessed.npz
            report.json
```

示例试验编号仅表示目录格式；实际编号来自 `trial_info.mat`。

每条 NPZ 可用 `np.load(path, allow_pickle=False)` 读取：

| 字段 | 含义 |
|---|---|
| `t[N]` | 原始 EMG 时钟，float64，秒；没有减去起点或同步偏移 |
| `emg_bandpass[N,10]` | 零相位带通信号，float32，μV |
| `emg_envelope[N,10]` | 整流、低通后的非负包络，float32，μV |
| `emg_normalized[N,10]` | 按受试者、按通道最大值归一化包络，无量纲，float32 |
| `normalization_max_uV[10]` | 实际使用的通道峰值；无效峰值为NaN |
| `channel_names[10]`、`bipolar_indices_1based[10]` | 列顺序及官方双极编号 |
| `channel_quality_flag[10]` | 位1：输入非有限；位2：输入恒定；位4：无有效归一化峰值；0仅表示通过这些数值检查 |
| `edge_valid[N]` | 是否位于所标记的首尾边界区之外 |
| 其他元数据 | 单位、采样率、版本、受试者/试验/任务编号、输入引用与SHA-256、归一化范围 |

`manifest.json` 保存完整配置、配置哈希、代码哈希、Python/NumPy/SciPy版本、输入目录、试运行范围、完成状态与逐人统计。逐试验报告保存源文件和输出文件SHA-256、时钟验证、通道异常及负值截断计数；逐人报告保存峰值和参与归一化的试验编号。

程序按受试者两阶段运行：先逐试验保存滤波包络，再使用该受试者全部所选试验峰值完成归一化，避免同时加载全部肌电。仅使用 `manifest.status == 'complete'` 的正式结果；计算失败时保留临时工作目录及失败报告供排查，原有正式结果不变。

质量标记目前不检测所有工频干扰、ECG污染、串扰或电极脱落。训练前仍需结合波形与频谱检查。角度标签及其质量标记继续从已有同步结果读取，按源文件和原始 EMG 时间戳关联，本流程不改写标签。

## 后续版本

版本名为 `vNNN_方法名`。滤波、通道、任务范围或归一化设置变化时新增配置；算法变化时在 `methods/` 下新增实现并接入公共流程。不要复制整套数据读取和导出代码。每次运行的代码哈希用于区分同一配置下的实现修订。
